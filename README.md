# MineFakePlayer Minecraft 假人机器人（Bot）

## 📖 项目简介

本工具是基于 **Mineflayer**（GitHub 开源项目）封装开发的 Minecraft 假人机器人进服软件，旨在为服务器玩家提供更加快速的配置以及一键进服。

---

## 🔧 技术背景

[Mineflayer](https://github.com/PrismarineJS/mineflayer) 是一个强大的 Node.js 库，用于创建 Minecraft 游戏机器人。它通过模拟游戏协议与服务器交互，使机器人能够像真实玩家一样登录、移动、聊天、执行指令等。

本工具在此基础上进行了封装，将复杂的 API 调用转化为简单的配置文件操作，让非技术用户能够轻松上手。

---

# 使用教程

欢迎使用本假人机器人工具！请按照以下步骤进行安装与配置，即可轻松管理您的 Minecraft 服务器假人。

---

## 📥 第一步：下载与解压

1. 下载本工具压缩包。
2. **务必解压**后才可使用，请勿直接在压缩包内运行。

解压后，您会在文件夹内看到以下核心文件：
- `node-v22.22.0-x64.msi` （运行环境安装包）
- `config.json` （配置文件）

---

## ⚙️ 第二步：安装运行环境

本工具基于 Node.js 运行，请先安装依赖环境：

1. 双击运行 `node-v22.22.0-x64.msi`。
2. 安装位置可保持默认或随意更改。
3. 一直点击 "Next（下一步）"，直至安装完成。

---

## 🛠️ 第三步：编辑配置文件

安装完成后，使用任意文本编辑器（如记事本、VS Code 等）打开 `config.json` 文件，根据您的需求修改配置。

### 基础连接设置

| 配置项 | 说明 |
| :--- | :--- |
| **`ip`** | 服务器的 IP 地址或域名（例如：`ragame.top`） |
| **`port`** | 服务器的端口号（例如：`23007`） |
| **`version`** | 游戏版本。**支持范围**：`1.8` 至 `1.21.11`（包括 1.9, 1.10, 1.11, 1.12, 1.13, 1.14, 1.15, 1.16, 1.17, 1.18, 1.19, 1.20, 1.21, 1.21.9, 1.21.11） |

### 连接与延迟控制

| 配置项 | 说明 |
| :--- | :--- |
| **`autoConnect`** | 假人断开后，间隔多少**秒**尝试重连。**推荐值**：`20` 左右。 |
| **`connectTime`** | 每个假人进入服务器的时间间隔（**秒**），避免同时涌入。**推荐值**：根据数量适当调大。 |

> ⚠️ **注意**：若假人数量较多（几十上百个），建议将重连和进服延迟设置得稍长一些，以免被服务器误判为压力测试。

### 随机聊天功能

| 配置项 | 说明 |
| :--- | :--- |
| **`min`** / **`max`** | 控制假人随机讲话的间隔时间（**秒**）。<br>例如设置 `30` 和 `60`，表示每个假人会在 30~60 秒之间随机说一句话。 |

### 其他功能

| 配置项 | 说明 |
| :--- | :--- |
| **`hd`** | 是否开启回显服务器聊天内容。<br>`true` 为开启，`false` 为关闭。假人较多时**建议关闭**，避免刷屏。 |

---

## ✍️ 第四步：自定义内容

您可以根据需要，自由编辑以下数组内容：

- **`commands`**：假人进服后自动执行的指令列表，按顺序执行。
  > 例如：`/register 密码 密码` 或 `/login 密码`

- **`message`**：随机聊天的内容库。
  > 💡 **提示**：除了普通聊天，您还可以在这里填写游戏内指令（如 `/ward shop`），让假人在不同地点活动，显得更自然。

- **`users`**：假人的游戏名称列表。
  > 添加多少个名字，启动后就会生成对应数量的假人。

---

## 🚀 第五步：启动与运行

1. 确保配置文件保存无误。
2. 双击运行文件夹内的启动程序（根据您的工具类型，可能是 `.bat` 文件或直接运行 `node` 命令）。
3. 观察控制台输出，即可看到假人陆续登录。
